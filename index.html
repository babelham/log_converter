GUIDE

사용 방법

빠른 시작

  1. 1
    코코포리아에서 HTML 로그 저장

    main과 other의 순서 연동이 필요하면 가능한 한 all 로그를 사용합니다.

  2. 2
    표정 수집 북마크릿 준비

    변환기의 표정 수집 북마크릿 복사를 누르고 새 북마크의 URL 칸에 등록합니다. 북마크 등록은 최초 한 번만 하면 되며, 다음 로그부터는 같은 북마크를 계속 사용할 수 있습니다. 처음이라면 왼쪽의 표정 수집 도움말에서 등록 과정을 먼저 확인하세요.

  3. 3
    코코포리아에서 표정 정보 수집

    룸 채팅 화면에서 북마크릿을 한 번만 실행합니다. 원하는 채팅 탭을 직접 누르고 각 탭의 로그를 위로 스크롤하면, 패널이 현재 탭 이름을 감지해 결과를 계속 누적합니다. 끝나면 완료 → TXT 다운로드를 누릅니다.

  4. 4
    HTML과 이미지 정보 파일 선택

    순서 기준 HTML에는 저장한 로그를, 이미지 정보 JSON/TXT에는 표정 수집 결과를 넣습니다. 표정과 인장을 정확히 반영하려면 두 파일을 함께 사용하는 것이 정식 절차입니다.

  5. 5
    로그 분석 및 설정

    로그 분석하기를 누른 뒤 필터와 스타일을 조정하면서 오른쪽 미리보기를 확인합니다.

  6. 6
    복사 또는 저장

    티스토리는 HTML 복사, 개인 보관·웹호스팅은 HTML 파일 저장을 사용합니다.

메시지별 표정 자동 매칭

코코포리아의 모든 채팅 탭에 표시되는 메시지 인장 주소를 수집해, 탭별로 같은 대사에 어떤 표정이 사용됐는지 연결하는 과정입니다. 아래 설명은 Chrome·Edge 기준입니다.

  1. 1
    북마크릿 코드 복사

    바로 위 또는 파일 업로드 영역 아래의 표정 수집 북마크릿 복사를 누릅니다. 버튼이 ✓ 북마크릿 복사 완료로 바뀌면 복사된 것입니다.

  2. 2
    북마크 관리자 열기

    Windows·Linux에서는 Ctrl+Shift+O를 누르세요. 또는 브라우저 오른쪽 위의 ⋮ 메뉴에서 북마크 및 목록/즐겨찾기 → 북마크 관리자를 엽니다.

  3. 3
    새 북마크 만들기

    북마크 관리자 오른쪽 위의 ⋮ 메뉴에서 새 북마크 추가를 누릅니다. 북마크바의 빈 곳을 오른쪽 클릭해 페이지 추가를 선택해도 됩니다.

  4. 4
    이름과 URL 입력

    이름은 ‘코코포리아 표정 수집’처럼 자유롭게 적습니다. 복사한 코드는 브라우저 상단의 주소창이 아니라, 새 북마크 등록 창 안에 있는 URL 칸에 붙여넣으세요. URL이 javascript:로 시작하는지 확인합니다. 이 등록은 최초 한 번만 하면 되고, 이후에는 저장된 북마크를 그대로 재사용합니다.

  5. 5
    코코포리아에서 실행

    수집할 룸의 채팅 화면을 열고 방금 만든 북마크를 한 번 누릅니다. 왼쪽 아래에 ‘수집 중’ 패널이 나타나며, 수집을 마칠 때까지 패널을 닫지 않습니다.

  6. 6
    채팅 전체를 훑기

    최근 메시지에서 시작했다면 위로 이동해 오래된 메시지까지 확인합니다. HOME 키를 여러 번 눌러 빠르게 위로 이동해도 됩니다. 실제로 채팅 위치가 바뀐 경우에만 새 화면을 한 번 수집하므로, 정지 화면의 재렌더링은 중복으로 추가되지 않습니다. HOME 재정렬에 따른 겹침도 병합됩니다.

  7. 7
    완료 후 결과 저장

    북마크릿 패널은 계속 켜 둡니다. Main·Info·Other 등 수집할 탭을 사용자가 직접 눌러 전환하고, 각 탭에서 오래된 메시지까지 위로 스크롤합니다. 탭만 바꾸면 현재 탭 이름이 자동 기록되므로 북마크릿을 다시 누를 필요가 없습니다. 모두 확인한 뒤 완료 → TXT 다운로드를 누르고 파일을 변환기의 이미지 정보 JSON/TXT에 넣습니다.

북마크가 실행되지 않을 때

  • 북마크의 URL이 정확히 javascript:로 시작하는지 확인합니다.
  • 코코포리아의 룸 채팅 화면에서 실행했는지 확인합니다.
  • 주소창에 코드를 붙여넣은 것이 아니라 북마크 편집 창의 URL 칸에 넣었는지 확인합니다.
  • 이미 ‘수집 중’ 패널이 떠 있다면 기존 패널에서 완료하거나 페이지를 새로고침한 뒤 다시 실행합니다.
북마크바 표시·숨기기는 Windows·Linux에서 Ctrl+Shift+B, macOS에서 Cmd+Shift+B입니다. 북마크바가 없어도 북마크 관리자나 브라우저 메뉴에서 만든 북마크를 실행할 수 있습니다.

티스토리에 게시

  1. HTML 복사를 누릅니다.
  2. 티스토리 글쓰기에서 편집 모드를 HTML로 바꿉니다.
  3. 코드를 붙여넣고 가능하면 기본 모드로 돌아가지 않은 채 저장·발행합니다.

파일로 배포

HTML 파일 저장으로 만든 파일 하나를 전달하면 됩니다.

노션

티스토리 보호글에서 제목만 보이는 경우에만 티스토리 보호글 호환 본문을 켜세요. 노션에 가져올 때만 이미지 내장과 노션 호환 정적 HTML을 함께 켜세요.

BGM 설정

  1. YouTube·외부 음원 주소 또는 Jukebox 목록을 BGM 목록 / 기본 링크 칸에 넣습니다.
  2. 미리보기 각 메시지의 BGM 지정을 누릅니다. 플레이리스트가 있으면 썸네일로 미리듣고 썸네일 밖 항목을 눌러 지정합니다. 이미 지정된 메시지에서는 BGM 수정·해제를 눌러 변경하거나 없앨 수 있습니다.
  3. 왼쪽의 설정된 채팅 목록을 누르면 해당 메시지가 있는 페이지로 이동하고 채팅 위치를 강조합니다.
  4. 독자가 BGM 활성화 버튼을 누르면 스크롤에 맞춰 전환되며, 다시 누르면 재생이 꺼집니다.

BGM 목록 북마크릿

  1. 위 버튼으로 북마크릿을 복사하고, 브라우저 북마크 편집 창의 URL 칸에 붙여넣습니다.
  2. YouTube 재생목록 또는 Jukebox.today 룸에서 같은 북마크를 실행합니다. 사이트는 자동으로 구분됩니다.
  3. YouTube에서는 재생목록을 아래로 읽어 곡을 수집하고, Jukebox에서는 재생목록·대기열과 필요한 페이지 내부 데이터를 읽어 목록별로 분류합니다.
  4. 완료된 목록을 복사하거나 TXT로 저장한 뒤 BGM 목록 / 기본 링크 칸에 붙여넣습니다.
문제가 있을 때 · 전용 북마크릿
북마크릿은 주소창이 아니라 북마크 편집 창의 URL 칸에 넣어야 합니다. 영상의 임베드 제한·지역 제한·자동 재생 제한은 YouTube와 브라우저 정책에 따라 달라집니다.

자주 생기는 문제

main과 other가 어긋나요
main 파일과 other 파일을 따로 넣는 것보다 원래 순서가 담긴 all 로그를 사용하세요.
인장이 나오지 않아요
외부 이미지 주소가 만료됐거나 이미지 정보 파일이 없을 수 있습니다. 도우미로 다시 수집해 보세요.
로그가 아주 길어요
기본 압축 출력과 가상 스크롤이 자동 적용됩니다. 노션 정적 출력은 긴 로그에서 훨씬 무거울 수 있습니다.
BGM이 자동 재생되지 않아요
브라우저가 사용자 동작 전 재생을 막을 수 있습니다. 로그의 BGM 활성화 버튼을 눌러 주세요.

파일 처리와 외부 연결

선택한 로그 파일은 브라우저 안에서 처리되며 서버로 업로드되지 않습니다. 외부 이미지·YouTube·외부 음원 BGM을 사용할 때만 해당 주소에 접속합니다.
